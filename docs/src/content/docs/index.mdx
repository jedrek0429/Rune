## What is Rune?

**Rune** is the app and service. A **rune** is one script running on Rune.

Rune is a small scripting platform for Discord. You upload a rune through Rune.Bot, Rune builds it into an executable artifact, and each invocation runs inside an isolated Firecracker microVM.

A rune receives a selected Discord event through **Rune.Api** and can call only the Discord operations Rune deliberately exposes. Rune.Api is derived from NetCord, but runes do not receive arbitrary NetCord objects, network access, or unrestricted access to the Rune process.

## References

**API Reference** documents Rune.Api, the script-facing API available to a rune. It covers events, inheritance, properties and methods, with language-specific signatures and links back to the corresponding NetCord API.

**Bot Reference** documents Rune.Bot, the Discord command surface used to register and manage runes. It is generated from the bot's command attributes and XML documentation, so the documentation lives next to the commands it describes.
