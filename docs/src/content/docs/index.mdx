## What is Rune?

**Rune** is the app and service. A **rune** is a script that runs on Rune.

Write a small Discord script, register it with Rune.Bot, and choose the events it responds to. Rune.Api gives your script the Discord data and actions available to it.

<CardGrid>
  <Card title="Write a rune">
    Write a rune in JavaScript, TypeScript, Python, Rust, C, or C++.
  </Card>
  <Card title="Register a rune">
    Upload it with Rune.Bot and manage it with the `/rune` commands.
  </Card>
  <Card title="React to Discord">
    Runes can respond to message creation, message deletion, reaction add, and reaction remove events.
  </Card>
  <Card title="Use Rune.Api">
    Read event data and call supported Discord actions from your script.
  </Card>
</CardGrid>

## Languages

### Rune.Api bindings

**TypeScript · Rust**

### Runtime support

**JavaScript · Python · C · C++**

Rune.Api bindings for these languages are planned.

### Planned

**C# · Java · PHP · Go · Bash · R · Ruby · Dart · Lua · Kotlin · Swift · F# · Zig · D · Nim · Scala**

Rune.Api keeps the same API across supported languages.
