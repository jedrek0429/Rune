A **rune** is a script registered with Rune. This example replies when someone sends `!hello`.

## 1. Add Rune to your server

<InstallRune />

Rune uses Discord's bot and application-command permissions.

## 2. Write the rune

<Tabs syncKey="language">
  <TabItem label="TypeScript">

```ts
if (message.content === "!hello") {
  await message.reply({
    content: `Hello, ${message.author.username}!`,
  });
}
```

  </TabItem>
  <TabItem label="Rust">

```rust
if message.content == "!hello" {
    message.reply(
        host,
        ReplyMessageProperties {
            content: Some(format!("Hello, {}!", message.author.username)),
        },
    )?;
}
```

  </TabItem>
</Tabs>

The `MessageCreate` event is available as `message`. Rust API calls use the `host` value shown above.

## 3. Register the rune

In Discord, use `/rune register`, choose a name, and attach the source file.

<Tabs syncKey="language">
  <TabItem label="TypeScript">

```text
/rune register name:hello file:hello.ts
```

  </TabItem>
  <TabItem label="Rust">

```text
/rune register name:hello file:hello.rs
```

  </TabItem>
</Tabs>

Rune builds the script and saves it.

## 4. Try it

Send:

```text
!hello
```

Rune receives the `MessageCreate` event and your rune replies.
