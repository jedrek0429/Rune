title: Security
description: How Rune keeps runes isolated and scoped.
---

Rune runs uploaded code in an isolated environment.

## Rune API access

A rune sees the Rune API surface selected by the contract.

Rune API methods define the Discord actions available to a rune. For example, `RestMessage.reply(...)` replies to the message that triggered the rune.

## Isolation

Each invocation runs separately with defined execution and data limits.

## Discord access

Runes communicate back and forth with Discord using Rune API, which is a specialised subset of [NetCord](https://netcord.dev/).
