Rune.Api reference

Rune.Api 0.1.0 is generated from the canonical API selection and maps to NetCord 1.0.0-beta.16.

The API surface is identical in every supported language. Only language-specific syntax and runtime semantics differ.

The language tabs are synchronised by DocFX. Choose a language once on a page and every language-specific section on that page follows the same selection.

  • TypeScript
  • Rust

TypeScript uses camelCase members, string snowflakes, Promise-returning host calls, and object-bound host access.

Rust uses snake_case members, native u64 snowflakes, Result<T, String> host calls, and an explicit mutable host reference.
